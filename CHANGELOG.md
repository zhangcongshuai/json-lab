# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-09-23

### Added
- JSON format / minify / validate
- Syntax highlighting (key, string, number, boolean, null)
- Indent guides and foldable JSON blocks (gutter ＋/－, double-click braces)
- Expand all / collapse all
- Timestamp conversion: Unix seconds / milliseconds / microseconds ↔ date/time
- Timezone helpers: local / UTC / UTC+8
- Dark / light theme
- Offline single-file Windows exe (`JSONLab.exe`)
